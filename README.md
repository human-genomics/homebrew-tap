# Homebrew tap for Note to Self

[Note to Self](https://github.com/human-genomics/note-to-self) is a chat with yourself that saves every note as Markdown on your own computer.

```sh
brew install human-genomics/tap/note-to-self
notetoself --install-app
```

The second command adds **Note to Self** to your Applications folder, so you can open it from Launchpad or Spotlight and keep it in the Dock.

The formula here is updated automatically by each release of Note to Self.
